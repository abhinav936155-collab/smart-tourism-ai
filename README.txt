SMART TOURIST - Python prototype

Run locally:
1. Install Python 3.10+
2. Open a terminal in this folder
3. Run: pip install -r requirements.txt
4. Run: streamlit run app.py

Open the local URL shown in the terminal. Streamlit provides a responsive browser
prototype that can be viewed on Android and iPhone on the same network or when
deployed to a hosting service.

This is a demo: destination information is sample content. Live maps, weather,
booking, payment, authentication and database features are not connected yet.
